## 実験条件

- 完了済みの元実験: `236962.rokko1`。**512 試行のそれぞれが 3,000,000 ステップを完了**した。
- 継続: 同じ各試行の最終チェックポイントから **追加 3,000,000 ステップ、累計 6,000,000 ステップ**。
- `global_prob=0.5`、seed `20260924`、独立 RNG、global trial ID `0..511` を維持。
- V100 8 台、64 試行/GPU。G キュー、CPU 8、RAM 64 GB、制限時間 24 時間。
- 前回の実測時間は 21:07:45。追加分も約 21 時間が目安だが、待ち時間は含まず、完了時刻を保証しない。
- 履歴は 1,000 ステップごと、チェックポイントは 10,000 ステップごとに保存。

`--resume --steps 6000000` の `steps` は追加量ではなく、絶対ステップの到達先を指定する。

## 2026-09-30 の進捗確認

03:08 JST の PBS 状態は `R`、V100 8 台を割当済み。開始は 9/29 19:17:29 JST。03:10 JST に全 8 ランクの保存履歴を確認し、各試行は 4,115,000〜4,122,000 ステップまで進んでいた。追加 3M の約 37.2% が完了している。

全ランクの最新履歴チャンクの SHA-256 が manifest と一致し、FSM・Amp・Unit・Comparator の新規出力を確認。RSM reset の追加記録もある。全ランクでチェックポイント保存が進み、ログ中に Traceback / RuntimeError / OOM / overflow の該当行はなかった。CUDA allocated は各ランク 1,404,225,536 bytes で元実験と同じ。この確認は稼働・保存の確認であり、途中時点の最適解率は再集計していない。

現在の平均速度から残り約 13.3 時間、9/30 16:30 頃の完了が目安。24 時間枠の期限は 9/30 19:17 頃。速度が維持された場合の推定である。確認データは `results/continuation-6m-20260928/status-20260930-0310.json` に保存した。[残っている論文向け実験の整理](2026-09-30-experiment-status.md)も参照。
