初回確認時刻には FSM x1〜x6 の持続出力を用いる。既存解析の変化点区間の開始をそのまま厳密な初到達時刻に置き換えない。内部状態の専用 decoder を必須条件に戻す必要はない。

A-3 は、3M の解析で最適解側への reset が 2 試行、同じ側への reset なしの出力減衰が 3 試行あったため、以前より優先する理由ができた。これは原因が Amp や GPU 実装だと確定した意味ではない。保存履歴の評価を先行し、必要な局所再現・単体較正に絞る。

当初の添付は現行セル空間を Instance 1 と仮定していたが、その後 b=8、Weights=[4,4,5,1,1,1] が Instance 2 と一致すると確認し、3M の解出力を Instance 2 として評価した。足りない比較条件を判断するときはこの更新を使う。ただし入力生成時の全制御設定の照合記録は引き続き整備する。
