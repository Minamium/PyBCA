## 試行数の決め方

前回実測は 32 trials/GPU、12.500 ms/step、GPU 割当約 670 MiB でした。線形換算では 64 trials/GPU × 8 GPU＝512 trials が約 20.8 時間ですが、これは新しい実測結果ではありません。現行コアでは VRAM を埋める前に実行時間が制約になる見込みです。

`scripts/plan_bca_ip_capacity.py` は試行数を倍増して上限を挟み、整数単位で二分探索します。推薦するのは実際に計測した試行数だけです。各候補では通常の BCA-IP、独立乱数、イベント履歴の逐次保存を使い、1,000 ステップ × 3 回を同期して測ります。

判定式は次です。

```text
予測秒数 = 3,000,000 × (最も遅い反復の秒/step + checkpoint秒/10,000) × 1.10
           + 初期化秒 + 最終checkpoint秒 + 3,600秒
予測秒数 <= 86,400秒
GPU peak allocated / reserved の大きい方 <= GPU総メモリの90%
```

10% の速度変動余裕と 1 時間の予約時間を確保します。履歴 flush は反復の計測時間に含まれます。独立した子プロセスで各候補を測り、前の候補の allocator を残しません。OOM は不適合として記録し、それ以外のエラーは測定失敗として停止します。

この単 GPU 測定は予備測定です。**最終的には判定・統計記録を組み込んだ 8 GPU 同時測定の最も遅い rank で再評価**して、本番の総試行数を決めます。未知の記録負荷を無視したまま推薦値を本番値にしないため、予備測定 JSON では `production_ready=false` としています。

出力: `results/capacity-236781.rokko1/plan.json` と候補ごとの測定 JSON / ログ。

## 本番投入前に確定する判定

ユーザー提示のレビューには次の 2 条件がありますが、どちらが現在のセル空間かは認定できていません。

| 条件 | a | b | c |
| --- | --- | ---: | --- |
| Instance 1 | [1,1,2,2,4,4] | 6 | [2,3,4,5,1,1] |
| Instance 2 | [1,1,2,2,4,4] | 8 | [2,2,1,5,5,5] |

必要なのは現行セル空間の a, b, c、および x1…x6 を読むセル座標と状態、または既存の判定方法です。FSM の Key Token を直接読む場合は、その領域と有効な状態を指定します。出力イベントの時間窓から読む場合は、窓幅・閾値・reset 処理・観測時点を結果を見る前に固定し、その判定として到達時間を報告します。単なる出力イベント初出を最適解発見とは扱いません。

係数が確定したら 6 bit 全 64 通りを列挙して制約充足と最適値・全最適解を確認します。A/B のいずれかが条件を満たした最初の時刻を 1 trial の到達時刻にし、A/B を 2 個の独立試行として数えません。乱数は `independent`、本番 seed は `20260924`、試行 ID は重複のない連番を予定しています。予備測定は別 seed のため、統計本番には混ぜません。

## 集計仕様

`scripts/summarize_bca_ip_trials.py` を追加しました。確定した decoder から、各独立試行につき次の JSONL を 1 行出す契約です。

```json
{"trial_id": 0, "observed_steps": 3000000, "first_hit_step": null, "decoder_sha256": "<判定定義のSHA-256>"}
```

到達時刻は完了した CA 更新回数で数え、初期状態が最適なら 0 とします。既存イベントログの 0 始まりの step は、そのまま到達更新回数にはしません。

- 成功: 制約を満たす最適解を 3,000,000 step 以内に観測。
- 失敗率: 全期間を観測して未到達だった試行の割合。Wilson 95% 区間を併記。
- 到達時間: 観測された成功試行の平均・中央値・標準偏差。未到達試行を含む無制限の平均とは区別。
- 3,000,000 step までの制限平均: 成功は到達時刻、未到達は 3,000,000 として平均する `mean(min(T_hit, horizon))`。
- 中断: 未到達のまま horizon より前に停止した試行は未完了。失敗に数えず、コホート全体の失敗率・制限平均は未確定として返す。
- 異なる decoder の混合、試行 ID 重複、予定試行数に足りない入力は拒否。

現在、この集計に渡せる認定済み到達時刻データはありません。人工データによる中断・未到達・境界時刻の 5 テストと、容量選択の 2 テストは合格しています。
