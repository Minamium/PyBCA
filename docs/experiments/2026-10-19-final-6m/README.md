## 判定の定義

同じユニットAまたはBが、同じ最適解ベクトルの出力を観測終点T=6,000,000まで100,000ステップ以上維持した試行を数える。両方が該当しても1試行。非最適・判読不能・別の最適解ベクトルへの変化で継続を切り、ユニット間をつないで期間を補わない。流量だけが変わり同じ最適解が続く区間は連結する。前回と同じ定義・読取りコードを使う。

横軸tまでに始まり、Tまで続いた最適解の継続区間を持つ試行の割合を描く。式は `F_T(t) = #{trial: s ≤ t, T−s ≥ 100000}/512`。sは片方のユニットで終点まで続く同一最適解の開始時刻（両方該当なら早い方）。Tまでの記録を使う事後評価であり、初到達率・オンライン判定率・厳密な内部状態の毎ステップ観測ではない。95% Wilson区間は各点の区間で、曲線全体の同時信頼帯ではない。

信号はFSMのx1〜x6から読み取る。最適性を参照せず流量変化を1万刻み・最短3万・罰則20で検出し、各区間全体を4分割して読む。合計4イベント以上かつ3分割以上に出力があればON、合計2以下ならOFF、それ以外は不明。その後に制約・目的値を評価する。条件1の最適解は `111100`、条件2は `110101` または `110110`、目的値はいずれも14。
